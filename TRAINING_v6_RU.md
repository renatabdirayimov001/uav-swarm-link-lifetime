# Обучение нейросетей для доработки статьи (код v6)

На этом компьютере обучаются только нейросетевые модели (LSTM, StaticGNN, StaticGNN без агрегации).
LET, KF-LET, GBT и новые базовые методы считаются отдельно, на CPU, и потом объединяются с вашими результатами.

## 1. Что нужно

- Видеокарта NVIDIA с 4 ГБ памяти или больше (подойдёт и Apple M1–M4).
  Без видеокарты всё тоже запустится, но займёт несколько суток.
- 8 ГБ оперативной памяти, 5 ГБ на диске.
- Python 3.10–3.13.

## 2. Установка (один раз)

Распакуйте архив в папку без пробелов и кириллицы в пути, например `C:\uav` или `~/uav`.
Откройте в этой папке терминал (Windows: PowerShell; Linux/Mac: Terminal) и выполните:

**Windows**
```
python -m venv venv
venv\Scripts\activate
```

**Linux / Mac**
```
python3 -m venv venv
source venv/bin/activate
```

Затем установите PyTorch с поддержкой видеокарты. Точную команду возьмите на
https://pytorch.org/get-started/locally/ (Stable → ваша ОС → Pip → Python → CUDA последней версии).
Она выглядит примерно так:
```
pip install torch --index-url https://download.pytorch.org/whl/cu128
```
На Mac достаточно `pip install torch`.

Остальные пакеты:
```
pip install numpy pandas scipy scikit-learn
```

## 3. Проверка (5 минут)

```
python run_v6.py check
```

В конце должно быть `CHECK PASSED`, а в строке `device:` — `cuda` (или `mps` на Mac).
Если там `cpu`, PyTorch установлен без поддержки видеокарты: переустановите его командой с pytorch.org.

## 4. Запуск

Всё сразу, одной командой:
```
python run_v6.py all
```

Или по шагам, в этом порядке (время указано для видеокарты уровня Tesla T4; на RTX 30xx/40xx быстрее):

| Шаг | Команда | Что делает | Время |
|---|---|---|---|
| 1 | `python run_v6.py reeval` | Опубликованные модели проверяются на 30 тестовых эпизодах вместо 6, без обучения | 15–30 мин |
| 2 | `python run_v6.py fading` | Реалистичный приём Hello с учётом замираний: обучение LSTM, StaticGNN и StaticGNN без агрегации, 3 сида | 1–1,5 ч |
| 3 | `python run_v6.py window` | LSTM с окном W = 4, 8 и 16 | 0,5–1 ч |
| 4 | `python run_v6.py tune` | Подбор гиперпараметров с равным бюджетом: 10 конфигураций на модель, только на валидации | 7–9 ч |
| 5 | `python run_v6.py final` | Лучшая конфигурация каждой модели, 3 сида, тест на 30 эпизодах (нужен шаг 4) | 2–3 ч |
| 6 | `python run_v6.py pack` | Собирает результаты в один архив | 1 мин |

Всего около 11–15 часов. Удобно запустить `all` на ночь.

**Важно:**
- Работу можно прервать (Ctrl+C) и запустить ту же команду снова: готовые прогоны пропускаются. Папку `out_v6` не удаляйте.
- Отключите спящий режим компьютера на время обучения.
- На Linux удобно запускать в фоне: `nohup python run_v6.py all > run.log 2>&1 &`.
- Ход работы пишется в `out_v6/progress.log`.

## 5. Что прислать

После шага 6 в папке появится файл `results_v6_<имя_компьютера>.zip` (обычно 20–100 МБ). Пришлите его в чат.

Если что-то упало с ошибкой, пришлите текст ошибки и файл `out_v6/progress.log`.

## 6. Какие замечания рецензии закрывают эти шаги

| Шаг | Замечание |
|---|---|
| reeval | 5: шесть тестовых эпизодов мало (теперь 30) |
| fading | 2: индикатор пропущенного Hello как «оракул» |
| window | второстепенное 1: чувствительность к длине окна проверена только на GBT |
| tune + final | 5: гиперпараметры не настраивались; отрицательный результат по агрегации |

## 7. Что изменено в коде

- `uav_swarm_sim.py`: опция `hello_model="fading"` — Hello принимается, только если мгновенный ОСШ
  с райсовскими замираниями не ниже порога. Со стандартными настройками симулятор выдаёт те же эпизоды,
  что и раньше (SHA-256 совпадают).
- `models.py`: ширина и число слоёв моделей стали параметрами; значения по умолчанию прежние,
  поэтому опубликованные контрольные точки загружаются без изменений.
- `run_v6.py`: новый скрипт экспериментов; процедура обучения та же, что в `run_v4.py`.
